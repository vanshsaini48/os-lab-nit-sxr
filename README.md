# Operating Systems Lab (ITL-251)

Practical implementations for the OS Lab course, B.Tech IT, 4th Semester.

**Institution:** NIT Srinagar  
**Session:** 2025-26

## Structure

- `lab3_unix_system_calls/` — write(), read(), open(), close(), lseek()
- `lab4_process_creation_using_fork/` — fork(), PID, PPID
- `lab5_threads_and_synchronization/` — POSIX threads, semaphores
- `lab6_synchronization/` — Mutex, Peterson's algorithm
- `lab7_cpu_scheduling/` — FCFS, SJF, Priority, Round Robin
- `lab8_memory_management/` — Partitioning, FIFO, LRU, Optimal, MFU, LFU, LIFO
- `lab9_disk_scheduling/` — FCFS, SSTF, SCAN, C-SCAN, LOOK, C-LOOK
